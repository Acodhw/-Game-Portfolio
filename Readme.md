# 포트폴리오 - 프로젝트 디렉토리 매핑 안내

이 저장소(또는 폴더)는 게임 프로그래머 포트폴리오에 소개된 프로젝트들의 원본 파일을 담고 있습니다.. 각 폴더가 포트폴리오의 어떤 프로젝트에 해당하는지 아래와 같이 안내합니다.

## 📁 Main Portfolio (완수된 프로젝트)
지금껏 완수한 주요 프로젝트들의 원본 에셋 파일들이 이 포함되어 있습니다.

* **`Code0Escape`** ➡️ **[Code0:Escape]**
  * 3D 팀프로젝트 / FPS
  * 블록 코딩 건을 이용해 종말의 움직임을 바꾸고 랜던 맵을 탈출하는 과제 제출 게임
* **`Rowlezjam_Entry`** ➡️ **[LowRez Jam: Elemental Adventure]**
  * 2D 개인 프로젝트 / 사이드뷰 플랫포머 슈팅
  * 원소를 조합해 새로운 생성 마법을 사용하며 빼앗긴 4개의 원소석을 찾는 게임

## 📁 AI Utilization Portfolio (AI 활용 프로젝트)
AI를 전면으로 활용해 코딩 및 제작한 프로젝트입니다.

* **`AIUnityAssignment`** ➡️ **[Tilt Over : Utilization Of AI]**
  * 3D 개인 프로젝트 / 쿼터뷰 퍼즐 액션
  * 던전 속에 숨겨진 힘을 이용해 숨겨진 길을 찾는 AI 생성 코드 기반 게임

## 📁 Feature Workes (기능 구현 및 히스토리)
과거 유니티를 공부하면서 구현해본 기능들이 존재하는 에셋 파일들입니다.
